# Enhanced AES Implementation with Key-Dependent Dynamic S-Boxes and Parallel CTR Mode

This repository archives the paper **“Enhanced AES Implementation with Key-Dependent Dynamic S-Boxes and Parallel CTR Mode: A High-Performance Cryptographic Framework”** by Puneet Chandna and Shashwat Mishra.

[Read the paper](paper.pdf).

Aside from this README, the repository contains only the paper. It does not provide implementation source code, runnable experiments, or materials to independently reproduce the paper's benchmark results. The performance and security results described in the paper have not been independently verified here.
